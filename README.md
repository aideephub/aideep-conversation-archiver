# AIDEEP Conversation Archiver

**English** | [فارسی](./README.fa.md)

Turn any raw AI conversation into a polished, self-contained HTML archive. No installation, no server, no account. Open it in a browser and paste.

---

## What it is

You copy the plain text of a conversation from any AI — ChatGPT, Claude, Gemini, DeepSeek, anything — and paste it into the archiver. The archiver packages it into a single `.html` file that:

- Opens in any browser
- Works offline, forever
- Has a table of contents, search, dark and light themes, and one-click copy buttons
- Can be printed, emailed, or dropped into any chat

Nothing is uploaded. Everything happens in your own browser.

## Features

- **Bilingual** — full English and Persian (RTL) support, including per-block code direction controls
- **Self-contained output** — one `.html` file, no external assets, no CDN, no fonts to fetch
- **Markdown export** — export the same conversation as a clean `.md` file
- **Optional local AI** — connect to Ollama to auto-title every block and ask follow-up questions inside the archive
- **Code-block controls** — LTR/RTL toggle per block, plus a live HTML preview for `html` blocks
- **Dark and light themes** — follows your system, remembers your choice
- **Live search, table of contents, collapsible messages, print-friendly layout**
