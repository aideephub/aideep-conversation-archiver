01

What is the Conversation Archiver?

A tiny browser tool that takes the plain text you copy from any AI chat — ChatGPT, Claude, Gemini, DeepSeek, or anything else — and packages it into a beautiful, self-contained HTML archive. The result is a single .html file you can open in any browser, share over email or messaging apps, print, or keep as a long-term record. You can also export the same conversation as a clean Markdown file, and — optionally — use a local AI to auto-title everything and answer follow-up questions inside the archive.

Offline & private

Nothing is uploaded anywhere. Everything — from pasting to previewing to downloading — happens in your own browser.

Zero dependencies

The generated file has no external links, no fonts to load, no scripts to fetch. It works offline, forever.

Beautiful by default

Table of contents, live search, dark and light themes, one-click copy buttons, collapsible messages, code-direction controls, and a print-friendly layout.

Optional local AI

Connect to Ollama on your own machine to auto-title every block and ask the archive follow-up questions — no cloud, no cost.

06

Ollama integration — optional local AI

Connect the archiver to Ollama — a free app that runs AI models on your own computer — and it can auto-title every block for you, and even answer follow-up questions right inside the builder and the generated archive. Ollama is entirely optional; everything else works without it. This section shows you how to set it up and use it.

Setting up Ollama (one-time, ~5 minutes)

1

Install Ollama

Download the free app from ollama.com and install it. It runs quietly in the background and hosts local AI models.

2

Start it with the browser-friendly setting

Open a terminal / command prompt and run the command for your system. This tells Ollama to accept requests from your browser.

Windows   set OLLAMA_ORIGINS=*  then  ollama serve
macOS / Linux   export OLLAMA_ORIGINS="*"  then  ollama serve
3

Pull at least one model

In another terminal, download a model, for example: ollama pull gemma4. Any model works — smaller models respond faster, larger ones are smarter.

4

Click “Connect to Ollama” in the archiver

Back in the archiver, open the Ollama Integration panel and click the connect button. When the lamp turns green, you're in.

Red lamp? That almost always means Ollama wasn't started with the OLLAMA_ORIGINS=* setting from step 2. Close it, run the command again, and retry.

On the builder page

The Ollama Integration panel sits in the right column, between the Project menu and the Formatting tips card. It has three controls: a connect button with a status lamp, a model dropdown (populated from your installed Ollama models), and an Auto-title button.

Lamp states: white = not tried yet, yellow = connecting, green = connected, red = failed.

What “Auto-title” does

Fills only empty fields

Anything you typed yourself is left exactly as-is. The model only fills in titles and archive details that are blank.

Matches the source language

English conversations get English titles. Persian conversations get Persian titles. And so on — the model is instructed to keep the language natural.

Order of operations

Every untitled block is titled one-by-one, in order. Then the Archive title and Subtitle are generated from the first user message and the first AI message — wherever they appear in the thread, so reordering or inserting blocks never breaks it.

Safe fallback

If the model returns nothing useful for a block, a short snippet from the message text is used instead — you never end up with an empty title.

“Ask AI” in the builder — per-block assistant

Every block in the builder carries an Ask AI button (a robot icon, next to the drag handle). Click it and an assistant panel slides in — on the left in English, on the right in Persian. The block you clicked is set as the context, so the model always knows what you're asking about. You can ask it to summarize, translate, rewrite, explain, or answer anything — and then write the reply straight back into your draft.

Four quick prompts

Tags above the input field fire instantly: Summarize, To Persian, To English, and To Arabic. They translate or summarize the current block with one click.

Streaming replies with a stop button

Responses appear token-by-token. While the model is writing, a red stop button replaces the send button — click it to abort, and whatever was written so far is kept.

Write the reply back into your draft

Below every AI reply there are four write-back buttons: Replace, Prepend, Insert below, and Append. They put the reply into your draft immediately — replacing the block, adding it before or after, or appending at the end. Replace keeps the block's role; inserted or appended blocks inherit the source role too (see §6 write-back below).

Remembers the conversation

As long as the panel stays open on the same block, follow-up questions keep the full conversation in context.

Ask a question…

Replace

The reply replaces the body of the message you were asking about. The role and title stay.

Prepend

The reply becomes a new message inserted before the source message. It inherits the source block's role — a reply about a User message is attributed to the User, not flipped to the AI.

Insert below

The reply becomes a new message inserted after the source message, again inheriting its role.

Append

The reply becomes a new message at the very end of the thread. Its role alternates from the last message — so a follow-up question after an AI reply lands as a User block.

Save HTML afterwards. Write-back changes what you see on screen but does not write to disk. Click Save HTML in the sidebar to keep the change.
Deleting an added block: messages added by write-back carry a small × button in their header. Clicking it removes just that message — the original conversation is never touched.

What the file looks like

# The Art of Color in AI Imagery **User:** Eitaa.com/AIDEEP **Created:** (blank) **Updated:** (blank) **Exported:** September 28, 2026 **Link:** (blank) ## Prompt: I love generating images with AI, but I have no idea how to pick colors that work well together… ## Response: Every color has three properties: hue, saturation, and value. A compelling image rarely needs many colors… --- Powered by [AIDEEP Chat Exporter](https://www.eitaa.com/AIDEEP)

Filename

Saved as {title-slug}-{YYYY-MM-DD}.md. If your title is empty, the slug is conversation-archive.

Labels are always English

Even if you're using the Persian UI, structural labels like **User:** and ## Response: stay in English so the file works with any tool. Only your body text preserves the original language.

Some fields are intentionally blank

Created:, Updated:, and Link: are placeholder labels with empty values. The archiver doesn't track those. They're not bugs — they simply keep the file compatible with other exporters.

Empty-block guard

In the builder, the button does nothing useful if every block is empty — you'll see a friendly toast asking you to add some text first.

Drafts, undo & import

Your work is autosaved in the browser, you can undo and redo structural changes, and you can move drafts between devices with JSON.

Autosave — per language

Every change to your archive is saved to this browser's local storage. Each interface language keeps its own draft, so switching between EN and FA never overwrites what you were working on. If a draft grows too large for plain storage, the archiver automatically compresses it before giving up.

Undo / Redo

Buttons at the top of the Project panel undo or redo structural changes — adding, deleting, moving, or inserting a block. Typing inside a field uses your browser's own undo, so the two never fight. Shortcuts: Ctrl+Z / Ctrl+Y.

Export draft as JSON

Downloads a small JSON file containing the title, subtitle, names, and every block. Perfect for backups or sharing a template.

Import

Accepts either a draft .json file or a previously generated .html archive. The data is read straight from the file — no re-typing needed. If the imported archive was made in a different language than your interface, you'll see a note explaining that the output will follow your current interface.

Markdown & plain-text import

The Import button also accepts .md, .markdown, and .txt files. A Markdown file exported from this archiver imports cleanly — roles and message bodies are preserved, and titles default to Message 1, Message 2, … (the Auto-title button can fill them in). Markdown from a third-party exporter works too, provided it follows the same # Title + ## Prompt: / ## Response: shape; a --- inside a message body and timestamp lines under a header are both handled correctly.

Paste-and-split

Click on the page background first, then press Ctrl + V. The archiver reads the clipboard, runs the same parsers used for file import, and splits the conversation into blocks — with the same confirmation dialog. Editable fields are excluded: pasting into a text area or title input still pastes as text, as before.

Load sample / Clear all

Load a small sample conversation to explore the tool, or clear everything and start from a blank draft.

Reset all local data

The nuclear option. Wipes every AIDEEP key stored in this browser — both language drafts, settings, and the saved Ollama model — and reloads. Use this if you want a completely fresh start.

About the heuristic parser: when a file or a paste has no clear # Title + ## Prompt: structure and no repeated speaker markers, the archiver falls back to a best-effort reader. It recognises the clipboard shapes from ChatGPT, Claude, and Gemini, and anything with a consistent Name: marker — but it is not a universal conversation reader. A paste with no recognisable structure imports as a single user block, which you can split by hand with the Insert button. This is by design.

Inside the generated archive

Every archive you produce ships with the same reading experience — plus the optional Ollama panel and Ask AI sidebar if you connected a model.

Sidebar table of contents

Sticky on the left (or right in RTL) with the active block highlighted as you scroll. Click any entry to jump straight to that message — it works in the preview and in the saved file alike.

Live search

Filter the table of contents by typing. Press / to jump straight to the search box.

Dark & light themes

Automatically follows your system, and remembers your choice. Press t to toggle.

One-click copy

Copy a whole message, its permalink, or any single code block. Each has its own copy button.

Collapsible messages

Collapse any message to its header, or collapse them all at once from the sidebar.

Print & Markdown

Two extra buttons in the sidebar: a Print pill for a clean paper layout, and a Markdown pill that exports the conversation as .md.

Reading progress

A thin gradient bar at the top shows how far the reader has scrolled through the conversation.

Ollama sidebar panel

Connect to a local AI, re-title the archive after the fact, and save the result back to disk.

Ask AI per message — with write-back

Click the robot icon on any message to open a resizable chat panel. Ask questions, summarize, or translate — then push the answer back into the archive with Replace, Prepend, Insert, or Append.

Code-block direction controls

Every code block has LTR and RTL buttons in its header to force the reading direction. A small Aa button switches between monospace and Vazirmatn for text/plaintext blocks. Your choices stick across edits in the same session.

HTML preview

Code blocks with the language html get a Preview button. One click renders the HTML in a sandboxed frame below the code, so you can see exactly what it produces without leaving the page.

Archive language is independent of the interface. You can use the manual in Persian and build an English archive — or vice versa. Pick the output language in the builder before generating, and the resulting file carries its own language and direction everywhere.

Tips & best practice

Give every block a title — or let the AI do it

Titles turn the table of contents into a real navigation aid. If you have Ollama connected, one click will title everything for you in the correct language.

One AI turn per block

If the AI sent several messages, split them into separate blocks. Readers can collapse what they don't need.

Wrap code in fences

Even a single line of code benefits from ``` fences — it gets syntax-appropriate styling, its own copy button, and LTR/RTL controls. Use ```html to unlock the live Preview toggle.

Back up important drafts

Autosave lives in this browser only. For archives you care about, export the JSON draft as well as the final HTML (and the .md if you want both formats).

Save HTML after auto-titling in an archive

Re-titling an existing archive won't write to disk by itself. Click Save HTML to persist the change.

Write back from Ask AI, then Save HTML

The four write-back buttons in the AI sidebar change what you see but don't save the file. When you're happy with the result, click Save HTML to write it to disk.

Use LTR/RTL buttons for mixed-language replies

If you have a Persian archive and get an English AI reply (or vice versa), click the LTR or RTL button under the reply to force the correct direction. The same applies to code blocks with mixed scripts.

Share the .html file directly

The archive is fully self-contained — email it, drop it in a chat, or upload it to any static host. No folder of assets required.

Paste the .md into your notes app

The Markdown export is deliberately clean — no HTML tags, no extra styling — so it looks right in Notion, Obsidian, Bear, GitHub, or anywhere else.
